## Featured project

### 🔭 [TESS Exoplanet Transit Analysis](https://github.com/akhileshm0507/tess-exoplanet-analysis)
A full pipeline on NASA TESS data for the hot Jupiter WASP-39b: cleaning the light curve, blindly recovering the orbital period (to within about 0.015% of the literature value), and fitting a physical transit model. The write-up includes an honest limitations section.
